05 — Selected projects

Things I've built.

Final-year project ↗

VQA Voyager

A Django web app for exploring cultural heritage sites. Visitors photograph an artifact and ask about it by voice, then get an answer on screen and read aloud. Built with an MVC structure and modular code, with conversation sessions stored in MySQL and a responsive Jinja and W3.CSS interface.

  • Django
  • Python
  • MySQL
  • Jinja2
  • YOLOv8
  • Whisper
Full-stack ↗

Stock Analysis AI

Market-intelligence app for NEPSE stocks. Celery workers sync live prices and crawl news into PostgreSQL. A weighted keyword and embedding scorer tags articles to companies, and rolling VWAP and volume checks flag anomalies. The FastAPI backend and Next.js frontend run as a single Docker Compose stack.

  • FastAPI
  • Next.js
  • Celery
  • Redis
  • PostgreSQL
  • Docker
Web app ↗

Kreeda

A cinematic, visual-novel-style platform for building, playing and sharing fantasy quests. It has a step-by-step quest builder in a React and TypeScript frontend, and a FastAPI backend that caches the sound effects, voices and visuals generated through the ElevenLabs API.

  • React
